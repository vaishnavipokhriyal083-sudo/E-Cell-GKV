# E-Cell GKV - Official Web Portal & Innovation Platform

The official web platform of the **Entrepreneurship Cell (E-Cell)** at **Gurukula Kangri (Deemed to be University), Haridwar, Uttarakhand**.

Built with **React**, **Vite**, and **Tailwind CSS**.

---

## 🚀 Features

- **Heritage & Deep-Tech Hero**: Combines GKV's prestigious cultural heritage with modern tech venture incubation.
- **Dynamic Live Stats**: Key metrics on startups incubated, seed grants facilitated, bootcamps conducted, and student reach.
- **Pillars & Vision**: Four-stage innovation framework (Ideate, Incubate, Accelerate, Network).
- **Flagship Initiatives**:
  - *E-Summit GKV*
  - *Ideathon & Hack-GKV*
  - *Venture Hatchery (Incubation Program)*
  - *Founder's Cafe & Masterclasses*
- **Interactive Event Registration**: Filterable upcoming/past events with instant modal ticket generation & QR pass preview.
- **Startup Hall of Fame**: Showcase of ventures founded by GKV students and alumni (VedicBio Formulations, GangaFlow Agrotech, CodePulse Engine, CampuzMart).
- **Core Leadership & Mentors**: Directory of faculty advisors and student coordinators.
- **Interactive Modals**:
  - **Pitch Your Startup Idea**: Multi-stage proposal submission for incubation.
  - **Join E-Cell**: Student executive body recruitment application.
  - **Event Pass Booking**: Instant delegate pass generation with custom registration ID.
- **FAQ & Contact Suite**: Accordion FAQ, campus location details (FET Haridwar), contact inquiry form, and newsletter.

## 📦 Getting Started

### 1. Installation

From the project root:

```bash
cd C:\Users\PC\.gemini\antigravity\scratch\ecell-gkv
npm install
```

### 2. Run the Development Server

```bash
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Production Build

```bash
npm run build
npm run preview
```

## 🏛️ About Gurukula Kangri Vishwavidyalaya
Gurukula Kangri (Deemed to be University) was founded on March 4, 1902, by Swami Shraddhanandaji with the objective of providing an indigenous alternative to Lord Macaulay’s British education system. Today, E-Cell GKV takes this vision forward by empowering students to become ethical founders and job creators.
